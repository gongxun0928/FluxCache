# Self-Check Gate

## Context

- Stage: design / plan / todo / coding / review / testing / doc-sync
- Tier: P0 / P1 / P2
- Round: 1

## Checklist

- [ ] Scope: 产出是否在声明范围内，无漂移？
- [ ] Correctness: 核心逻辑/决策是否正确？
- [ ] Completeness: 是否覆盖上一阶段的全部要求？
- [ ] Risk: 有无遗漏的高/中风险？
- [ ] Testability: 产出是否可验证？
