# Bug Triage 缺陷分级标准

> 与 `change-tiering-and-qg.mdc` 对齐，供后续 bug 修复 issue 复用。

## 分级定义

| 等级 | 含义 | 示例 |
|------|------|------|
| **P0** | 生产崩溃、数据丢失、安全漏洞 | 核心路径崩溃、数据损坏、权限绕过 |
| **P1** | 核心功能异常、重要性能退化 | 读/写路径错误、明显性能回退、RPC 契约违反 |
| **P2** | 次要功能、边界条件、文档/注释 | 非关键路径、文档错误、日志不准确 |

## 升级规则（命中任一即升级）

- 涉及协议/API/公共接口变更：至少 P1。
- 涉及数据结构或持久化格式变更：至少 P1。
- 涉及权限、认证、配额、计费、风控：直接 P0。
- 涉及主流程稳定性开关、容错、降级策略：至少 P1。
- 无法在当前上下文清晰说明影响边界：按 P1 处理。

## 使用方式

- 新建 bug 修复 issue 时，在 issue 中标注分级（如 `[P1]`）。
- 修复时参考 `docs/bug-fix-template.md` 填写修复说明。
- 若为回归类 bug，在 `tests/regression/` 中增加对应回归用例，并打上 `regression` 标签。
